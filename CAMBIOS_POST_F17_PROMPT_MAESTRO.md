# PC Game Archive — Prompt maestro operativo tras F17

**Fecha:** 05/10/2026

## Objetivo

Convertir las reglas, estándares y lecciones aprendidas durante F17 en un protocolo reutilizable que deba consultarse antes de abordar cualquier nueva pieza.

## Cambios

- Se añade `PROMPT_MAESTRO_PRESERVACION_COMPATIBILIDAD.md`.
- Se consolida el flujo obligatorio de preservación, copia de trabajo, compatibilidad, documentación y publicación.
- Se incorporan criterios explícitos de parada cuando la evidencia no sea suficiente.
- Se refuerza el trabajo conversacional paso a paso: una acción, un resultado y una decisión antes de continuar.
- Se incorpora un protocolo específico para ediciones multi-CD/multi-soporte:
  - cada disco se preserva y verifica individualmente;
  - la pieza se gestiona como un único conjunto;
  - la preservación global solo se considera completa cuando todos los soportes requeridos tienen un estado coherente;
  - las pruebas de compatibilidad deben cubrir los cambios de disco cuando proceda.
- README actualizado para declarar el prompt maestro como referencia operativa obligatoria.

## Principio

El primer piloto, Red Baron 3-D, es una referencia de proceso, no una plantilla de resultados. Ninguna estructura, protección, formato o compatibilidad debe extrapolarse automáticamente a la siguiente pieza.
