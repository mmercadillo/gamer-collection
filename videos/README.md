# Vídeos introductorios

Guardar aquí los vídeos MP4 optimizados con el nombre exacto del slug de la ficha: `<slug>.mp4`.

En `juegos.json` configurar `"video_intro": true` únicamente cuando exista el fichero correspondiente.
El generador omite el reproductor si el MP4 no existe, y no modifica los vídeos.

La publicación pública de vídeos debe realizarse únicamente cuando se disponga de derechos o autorización suficiente.
