# PC Game Archive — Entornos de referencia de preservación y compatibilidad

**Fecha:** 18/10/2026  
**Ámbito:** operación continua posterior a F17

## Objetivo

Publicar de forma transparente y reproducible las bases de hardware, software y procedimiento utilizadas por PC Game Archive para crear másteres de preservación y validar compatibilidad, sin exponer información operativa sensible.

## Cambios

- Se incorpora la categoría documental **Entornos de referencia**.
- Se publica **PCGA-MASTER-01**, estación de referencia para preservación digital.
- Se publica **PCGA-LAB-01**, laboratorio de referencia para ejecución y compatibilidad.
- Los documentos públicos excluyen rutas internas, hostnames, números de serie, identificadores PNP/USB completos y topología de almacenamiento.
- PCGA-MASTER-01 enlaza al estándar de preservación y al procedimiento de caracterización óptica, sin sustituir la evidencia específica de cada adquisición.
- PCGA-LAB-01 enlaza al estándar de guías de ejecución y mantiene la obligación de registrar la configuración concreta de cada prueba.
- Se añade una novedad pública del 18/10/2026.
- `propiedades.json` actualiza `ultima_actualizacion` a `2026-10-18`.

## Resultado

La documentación pública permite conocer con qué base técnica trabaja el archivo y cómo se separan preservación y compatibilidad, manteniendo fuera de la web los detalles de infraestructura que no aportan reproducibilidad.
