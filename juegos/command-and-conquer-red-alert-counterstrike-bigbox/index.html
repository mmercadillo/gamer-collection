Command & Conquer: Red Alert - Counterstrike

Command & Conquer: Red Alert Counterstrike es la primera expansión oficial de Command & Conquer: Red Alert, desarrollada por Westwood Studios. Añade 16 nuevas misiones para ambos bandos, nuevas unidades experimentales y mapas adicionales para el modo multijugador. Esta expansión continúa utilizando el motor de estrategia en tiempo real que consolidó a la saga Command & Conquer como una de las franquicias más influyentes del género durante los años noventa. La edición física distribuida por Virgin Interactive incluye CD-ROM y manual de instalación, representando una de las primeras expansiones comerciales lanzadas para juegos RTS en PC compatibles Windows 95.
